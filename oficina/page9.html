Prompt para Specs
COPIE ESTE PROMPT
Kiro, cria um projeto Node.js/TypeScript para uma
lista de tarefas (to-do list).

Funcionalidades:
1. Criar tarefa (título, descrição, prioridade)
2. Listar tarefas (filtro por status: pendente/concluída)
3. Marcar tarefa como concluída
4. Deletar tarefa

API REST com Express. Use Jest para testes.
Cria a spec completa: requirements, design e tasks.
Depois: "Kiro, executa todas as tasks" → Projeto implementado com testes em ~5 minutos
