O que é Kiro?
IDE com IA que funciona como parceiro de desenvolvimento — diferente de outros assistentes, ela lê e escreve em múltiplas ferramentas simultaneamente.
📐
Specs
Transforma ideia em Requirements → Design → Tasks → Implementação. EARS format.
🪝
Agent Hooks
Automações event-driven: salvou .ts → roda lint; criou teste → executa suite.
🧭
Agent Steering
Contexto persistente: product.md, tech.md, structure.md
🔌
MCP ★ A ESTRELA
Conecta Kiro a Jira, Confluence, GitHub, QMetry, Datadog… Próximos slides.
