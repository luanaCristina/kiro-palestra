Hooks: Automações
Automações que rodam quando eventos acontecem na IDE.
EXEMPLO: Lint on Save
{
  "name": "Lint on Save",
  "version": "1.0.0",
  "when": {
    "type": "fileEdited",
    "patterns": ["*.ts"]
  },
  "then": {
    "type": "runCommand",
    "command": "npm run lint"
  }
}
Event Types
• fileEdited
• fileCreated
• fileDeleted
• promptSubmit
• agentStop
• userTriggered
Como criar: Command Palette → Open Kiro Hook UI → configurar evento + ação
