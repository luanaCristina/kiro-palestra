"Kiro, cria uma spec para automação de testes"

2
"Kiro, executa todas as tasks"

4
"Roda os testes e envia pro QMetry no card SDC-8"
→ npm run test:qmetry -- --card SDC-8 · 182/183 pass · Test Cycle criado
5
"Cria uma página Confluence explicando os testes"
→ Página completa com cenários, comandos, rastreabilidade — também via MCP Atlassian
6
"Faz deploy no Render"
→ Aplicação online com dados demo · appointment-scheduling-api.onrender.com
